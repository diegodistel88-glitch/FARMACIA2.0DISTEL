# UCI · Gestión de Indicaciones Médicas y Farmacia

Sistema web para gestionar indicaciones médicas, acciones de enfermería y pedidos de farmacia en UCI Adultos.

## 🚀 Demo en vivo

👉 [Ver demo](https://TU-USUARIO.github.io/uci-indicaciones/)

## 📋 Características

- **Pestaña Médico**: Registrar indicaciones con buscador sobre vademécum
- **Pestaña Enfermería**: Ejecutar indicaciones por horario + indicaciones propias
- **Pestaña Farmacia**: Recepción automática de materiales solicitados
- **Buscador inteligente**: Busca por nombre, código o tipo
- **Materiales automáticos**: Por tipo de indicación y vía
- **Horarios automáticos**: Según frecuencia seleccionada
- **Sin servidor**: Todo funciona en el navegador (simulación con GitHub Pages)
